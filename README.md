# Portfolio Chaminade ADJOLOU — refonte cinématique

Refonte du portfolio (Next.js 14, TypeScript, Tailwind, Framer Motion) inspirée d'un reel « Cinematic portfolio website animation ».

## Lancer
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # export statique dans out/
```
Ajouter `?sansintro` à l'URL pour passer l'intro.

## Sections
Intro (lettres qui tombent : CHAMINADE puis DONCHAMINADE) · Accueil · À propos · Services · Projets · Composants (écrans mobiles) · HELLO WORLD (matrice de points jouable) · Contact.

## Contenu
Repris du dépôt `Donchaminade-folio-pro` (profil, compétences, expériences, blocs de compétences, projets et images).
Captures Picon : fiche Google Play `com.photopicon.app`.
