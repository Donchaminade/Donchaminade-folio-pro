# Portfolio Chaminade ADJOLOU — refonte cinématique

Refonte du portfolio (Next.js 14, TypeScript, Tailwind, Framer Motion) inspirée d'un reel « Cinematic portfolio website animation ».

## Lancer
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # export statique dans out/
```
Ajouter `?sansintro` à l'URL pour passer l'intro.

## Sections
Intro (lettres qui tombent : CHAMINADE puis DONCHAMINADE) · Accueil · À propos · Parcours · Services · Tarifs · Projets · Distinctions · Communauté · Galerie · Écrans · HELLO WORLD · Contact.

Le thème sombre est le défaut. Le choix de thème et la langue (français par défaut) sont gardés dans le navigateur.

## Contenu
Repris du dépôt avant la refonte : profil, statistiques, compétences, savoir-être, parcours, distinctions, formation, communautés, pages animées, projets et les photos présentes dans l'historique.
