# Next.js 16.3 : quand le framework s’écrit aussi pour les agents IA

**Slug :** `nextjs-16-3-agents-ia-navigations-instantanees`  
**Catégorie :** tech (Tech & Dev)  
**Statut cible :** publié après brouillon → aperçu → validation  

---

Next.js 16.3, publié le 3 août 2026, n’est pas seulement une version plus rapide. C’est la première fois que le framework assume clairement qu’**un agent IA fait partie de la boucle de développement** — et qu’il écrit aussi pour lui : docs versionnées, skills, erreurs actionnables, MCP de compilation. En parallèle, **Instant Navigations** rend enfin les clics aussi snappy qu’une SPA, sans abandonner le modèle serveur.

## Ce que 16.3 change pour tout le monde

Même sans toucher à la config, l’upgrade apporte des gains mesurés par Vercel :

- Jusqu’à **90 % de RAM en moins** sur `next dev` (cache disque + éviction mémoire Turbopack).
- **Builds plus rapides** : FileSystem Cache aussi sur `next build` (jusqu’à 5,5× sur certains CI).
- **TypeScript 7** pour le typage pendant le build.
- **Rendu serveur** : streams Node.js natifs — jusqu’à 22 % de requêtes en plus sous charge.
- Moins de requêtes de prefetch, assets immuables entre déploiements, `catchError`, `import.meta.glob`, **root params**.

Sources : [Next.js 16.3](https://nextjs.org/blog/next-16-3), [v16.3.0](https://github.com/vercel/next.js/releases/tag/v16.3.0).

Les navigations instantanées sont **opt-in** (`cacheComponents` + `partialPrefetching`). Elles deviendront le défaut plus tard. Les docs agents s’activent dès `next dev`.

## Le framework s’écrit aussi pour les agents

Détail : [AI Improvements](https://nextjs.org/blog/next-16-3-ai-improvements).

### AGENTS.md versionné

`next dev` écrit un bloc dans `AGENTS.md` qui pointe vers `node_modules/next/dist/docs/` — la doc de *votre* version. Opt-out : `agentRules: false`.

### Skills first-party

- `next-dev-loop`
- `next-cache-components-adoption`
- `next-cache-components-optimizer`
- `next-partial-prefetching-adoption`

```bash
npx skills add vercel/next.js --skill next-dev-loop
```

### Erreurs, Markdown, MCP

Instant Insights : Stream / Cache / Block (`export const instant = false`). Bouton Copy prompt + pages `/docs/messages`. MCP : `get_compilation_issues`, `compile_route`. Docs : suffixe `.md` ou `Accept: text/markdown`.

## Instant Navigations

```ts
const nextConfig = {
  cacheComponents: true,
  partialPrefetching: true,
};
```

Shell préchargé, Partial Prefetching, ISR + shell, Instant Insights, Navigation Inspector, helper Playwright `instant()`.

## Studio en Afrique de l’Ouest

Même rituel que ce portfolio : **brouillon → aperçu → validation humaine**. Un agent n’a pas le droit de publier.

## Expérimental

- React Compiler Rust dans Turbopack

## Checklist

1. `npm install next@latest`
2. Committer le bloc `AGENTS.md` s’il apparaît
3. Cache Components sur une branche, pas en prod à l’aveugle
4. Interdire merge / deploy à l’agent
5. Un test `instant()` sur les liens les plus cliqués

> Le framework accélère le premier jet et le premier clic. La confiance se gagne à la relecture — humaine.
